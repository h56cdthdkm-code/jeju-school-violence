# PRD v2: 제주 학교폭력 가해자 검거 현황 보기 도구

> PRD(제품 요구사항 문서) = "무엇을, 왜, 누구를 위해, 어디까지 만들지"를 만들기 전에 적어 두는 문서입니다.
> 이 문서는 `prd_school_violence_tool.md`(v1)를 **데이터 파일을 직접 열어 확인한 결과**로 고친 v2입니다. v1 파일은 그대로 두었습니다.
> 원칙: **파일에서 확인한 것만 쓰고, 확인하지 못한 것은 "확인 필요"로 남겼습니다.**
> 이 문서의 숫자는 CSV 파일에서 직접 계산해 v1의 숫자와 모두 일치하는 것을 확인했습니다. (불일치 0건)

| 10 | 완료 기준 문장 점검 | ④ "시작 연도 > 끝 연도 안내"(예외 처리)를 핵심에서 **추가 확인**으로 옮기고, 핵심 시나리오 마지막 단계(자료의 한계 확인)를 덮는 **⑤를 새로 추가** | 슬라이드의 "좋은 완료 기준" 3가지(눌러서 확인 · 핵심 시나리오 안 3~5개 · 데이터로 가능)에 맞춤 |

## 1. 한눈에 보는 기획표

| 항목 | 내용 |
|---|---|
| 대상·사용 상황 | 학생·학부모·교사·정책을 공부하는 사람이, 제주 학교폭력 가해자 검거가 연도별·유형별로 어떻게 달라졌는지 확인할 때 |
| 해결할 문제 | 원본 CSV는 연도별 숫자만 나열돼 있고 합계가 없으며, 엑셀에서 열면 글자가 깨진다. 그래서 어느 해가 가장 많았는지, 어떤 유형이 늘었는지 알려면 직접 더하고 비교해야 한다 |
| 입력·결과 | 제주 연도별·유형별 검거 CSV → 연도별 표 · 합계 · 유형 비율 · 전년 대비 증감 · 주의사항 |
| 핵심 기능 | 연도별 표, 연도 범위 고르기, 유형 고르기, 합계·비율·전년 대비 자동 계산, 잘못된 입력 안내, 자료의 한계 안내 |
| 완료 기준 | 5장의 ①~⑤(핵심 시나리오 5개)를 직접 눌러서 모두 확인했을 때 통과한다. 시작 연도가 끝 연도보다 큰 경우 등 예외 처리는 "추가 확인"이다 |
| 이번에 제외할 것 | 인천 자료와의 합산·비교 · 학교·가해자·피해자 식별 · 원인 단정 · 신고 접수/상담 · 로그인 · 실시간 연동 · 기기 간 공유 |

### 2-2. 이 자료의 한계
1. **합계 열이 없다.** 화면에서 더해서 계산한다.
2. **단위를 모른다.** (인원/건수 확인 필요)
3. **「기타」가 무엇인지 모른다.** 2014년 11 → 2025년 77로 가장 많이 늘어난 칸이라 해석에 주의가 필요하다.
4. **검거 통계다.** 실제 학교폭력 발생 규모와 같지 않다.
5. **작은 숫자가 있다.** 금품갈취는 6~23(연 단위)이라 몇 건 차이가 크게 보일 수 있다.
6. 학교급·월·학교·피해자 정보는 자료에 **없다.**

## 3. 배경과 문제 정의

| # | 문제 | 근거 (파일에서 확인) |
|---|---|---|
| P1 | **합계가 없다** | 제주 파일에 합계 열이 없어 가장 많은 해를 알려면 직접 더해야 한다 |
| P2 | **전년 대비 변화와 비율이 없다** | 연도·유형별 숫자만 있어 증감과 비율은 계산해야 한다 |
| P3 | **「기타」가 무엇인지 모른다** | 기타 367건(15.4%), 2025년만 77건이다 |
| P4 | **단위를 모른다** | 인원인지 건수인지 파일에 설명이 없다 |
| P5 | **검거 통계를 발생 규모로 오해하기 쉽다** | 파일 제목이 "가해자 검거 현황"이다 |
| P6 | **작은 숫자의 변동을 과장하기 쉽다** | 금품갈취 6~23 등 |
| P7 | **파일을 열면 글자가 깨진다** | EUC-KR 인코딩 |

(v1의 "두 자료를 합치면 안 된다"는 문제는 인천을 핵심에서 뺀 v2에서는 6장 "시간이 남으면"으로 이동했습니다.)

## 4. 목표와 하지 않을 것

### 목표
1. 제주 자료를 연도별 표와 **합계·비율·전년 대비 증감**으로 한 화면에서 볼 수 있게 한다.
2. 자료의 **한계(단위 불명, 「기타」 불명, 검거 통계 등)**를 화면에 적어 오해를 줄인다.
3. 코딩을 처음 해도 이해할 수 있는 **HTML 파일 하나**로 만든다.

### 하지 않을 것 (이번 범위 밖)
- 인천 자료와 더하거나 한 그래프에 섞어 비교하기 (v2에서 삭제: 대상·지역·기간이 달라 의미 있는 비교가 안 됨)
- 인구 대비 비율, 학교급·월별 분석 (자료에 열이 없음)
- 특정 학교·가해자·피해자 식별 (자료에도 없음)
- 늘거나 줄어든 이유를 단정하기
- 신고 접수·상담, 로그인, 실시간 연동, 기기 간 공유

## 5. 핵심 시나리오와 완료 기준

### 핵심 시나리오 (이것 하나를 끝낸다)
> **"제주 학교폭력 가해자 검거 현황에서, 연도 범위와 유형을 바꿔 가며 합계·비율·전년 대비 증감을 확인한다."**

사용자는 사이트를 열고 → 12개 연도 표를 보고 → 연도 범위를 좁히거나 유형을 골라 → 합계·비율·전년 대비를 읽고 → 화면 아래의 자료 한계 안내를 확인한다.

### 핵심 기능 (v1의 F번호 대응)

| 기능 | v1 번호 | 내용 |
|---|---|---|
| 연도별 표 | F2 | 12개 연도, 유형별 숫자, 합계, 최고 연도 표시 |
| 연도 범위 | F3 | 시작·끝 연도를 고르면 그 범위만 보이고 기간 합계가 바뀜 |
| 유형 고르기 | F4 | 유형을 켜고 끌 수 있고, 선택한 유형의 최댓값이 강조됨 |
| 유형 비율 | F5 | 12년 기준 유형 비율 |
| 전년 대비 | F6 | 증감 숫자와 %. 전년이 없는 첫 해는 "-" |
| 잘못된 입력 | F10 | 시작 연도가 끝 연도보다 크면 안내, 유형을 모두 끄면 안내 (완료 기준에서는 "추가 확인") |
| 자료의 한계 안내 | F9(제주) | 2장 2-2의 한계를 화면 아래에 표시 |

### 완료 기준 (직접 눌러서 확인)

핵심 시나리오를 처음부터 끝까지 덮는 **5개**입니다. 모두 화면에서 직접 해 보고 통과/실패를 말할 수 있고, 2장 「사용 데이터」에 적힌 데이터만으로 확인할 수 있습니다.

| # | 확인 방법 | 이렇게 나와야 통과 | 시나리오 단계 |
|---|---|---|---|
| ① | 사이트를 연다 | 연도 **12개(2014~2025)**가 나오고, 2025년 합계 **325**에 "최고" 표시가 있다 | 표를 본다 |
| ② | 연도 범위를 **2020~2025**로 바꾼다 | 6개 연도만 남고 기간 합계가 **1,364**이다 | 범위를 좁힌다 |
| ③ | 유형을 **「성폭력」만** 켠다 | 성폭력 열만 남고 **2024년 71**이 강조된다 | 유형을 고른다 |
| ④ | 2025년 줄을 본다 | 전년 대비 합계 **+77 (+31.0%)**, 폭력 **+49 (+39.2%)**이고, 2014년의 전년 대비는 "-"이다 | 합계·비율·증감을 읽는다 |
| ⑤ | 화면 아래를 본다 | "단위(인원/건수) 확인 필요", "검거 통계이며 실제 발생과 같지 않다", "「기타」의 구성은 자료에 없다"와 **자료 기준일 2025-12-31**(파일 이름의 날짜)이 보인다 | 자료의 한계를 확인한다 |

**추가 확인 (핵심 시나리오 밖, 예외 처리)**

| 확인 방법 | 이렇게 나와야 통과 |
|---|---|
| 시작 연도를 끝 연도보다 **크게** 고른다 | "시작 연도를 끝 연도보다 작게 골라 주세요"라고 안내하고 오류가 나지 않는다 |
| 유형을 **모두** 끈다 | 유형을 고르라는 안내가 나오고 오류가 나지 않는다 |

※ 출처(URL)는 아직 확인되지 않아 완료 기준에 넣지 않았습니다. 주소를 확인하면 ⑤에 "출처가 보인다"를 추가합니다.
