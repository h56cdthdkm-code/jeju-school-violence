# 제주 학교폭력 가해자 검거 현황 보기

제주 학교폭력 가해자 검거 현황(2014~2025)을 연도별로 보고, 연도 범위와 유형을 바꿔 **합계 · 비율 · 전년 대비 증감**을 확인하는 웹 페이지입니다. HTML 파일 하나로 만들었습니다. (핵심은 제주 자료이고, 인천 소년범죄 자료(2016~2018)를 보는 탭도 함께 들어 있습니다.)

- 배포 주소: (Vercel 배포 후 여기에 추가)
- 기획 문서: [docs/PRD.md](docs/PRD.md) (PRD v2)

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 화면과 데이터가 모두 들어 있는 페이지 (제주·인천 탭, 브라우저로 열면 바로 실행) |
| `docs/PRD.md` | 제품 요구사항 문서(PRD) v2. 핵심 시나리오와 완료 기준이 적혀 있습니다 |

## 사용 방법
1. `index.html`을 브라우저로 엽니다.
2. 시작·끝 연도를 고르면 그 기간의 합계가 나옵니다.
3. 유형(폭력, 금품갈취, 성폭력, 기타)을 켜고 끌 수 있습니다.
4. 화면 아래의 **자료의 한계**를 함께 읽어 주세요.
5. (선택) 위쪽 탭에서 **「인천 소년범죄」**를 누르면 인천 자료(2016~2018)를 볼 수 있습니다. 제주와 대상·지역·기간이 달라서 **더하거나 직접 비교하면 안 됩니다.**

## 자료와 한계
- 자료: 경찰청 제주특별자치도경찰청 「학교폭력 가해자 검거 현황」 (파일 기준일 2025-12-31, 2014~2025년)
- 출처 주소(URL)와 숫자의 단위(검거 인원인지 건수인지)는 **확인 필요**입니다.
- 검거 통계이며 실제 학교폭력 발생 규모와 같지 않습니다. 「기타」의 구성도 자료에 없습니다.
- (인천 탭) 인천광역시 「소년범죄 현황」 (파일 기준일 2018-12-31, 2016~2018년 3년). **학교폭력만이 아니라 소년범죄 전체**이며 학교폭력 구분이 없습니다. 3년뿐이라 추세를 판단하기 어렵고, 단위도 확인 필요입니다.
- 늘거나 줄어든 이유는 자료에 없으므로 단정하지 않습니다.
